# 복습 플래너 (PWA, 1단계 MVP)

망각곡선 간격(기본 1·3·7·15·30일)으로 복습일을 자동으로 잡아 주는 플래너형 웹앱입니다. 폰과 PC 모두에서 쓸 수 있습니다.

## 기능
- 빠른 입력: `행정법 3장 #행정법` 형식. 여러 줄을 붙여 넣으면 한 번에 등록됩니다.
- 오늘 화면: 잊음 / 애매 / 기억남 평가, 되돌리기, 많이 밀린 항목부터 표시
  - 잊음: 첫 간격부터 다시 시작
  - 애매: 같은 간격을 한 번 더
  - 기억남: 다음 간격으로 진행
- 하루 상한을 넘은 복습은 "다음 날들로 나누기" 버튼으로 분산
- 달력: 날짜별 예정 복습 수 (앞으로 계속 '기억남'이라고 가정한 예상치)
- 과목별 진행률
- 설정: 복습 간격, 하루 시작 시각, 하루 상한, 시험일(이후 복습은 시험 전날로 당김)
- JSON 내보내기/가져오기, 시간여행(테스트용 날짜 이동)

## 구조
| 파일 | 역할 |
|---|---|
| `scheduler.js` | 스케줄 계산(순수 함수). 다음 복습일은 저장하지 않고 항목+로그로 매번 계산 |
| `app.js` | UI와 localStorage 저장 |
| `sw.js`, `manifest.json` | 오프라인 지원과 홈 화면 설치 |
| `test/` | 스케줄러 단위 테스트 (`npm test`) |

## 로컬 실행
```
python -m http.server 8000     # 또는 npm run serve
```
브라우저에서 http://localhost:8000 을 열면 됩니다.

## 폰에 설치하기 (HTTPS 배포 필요)
1. GitHub 저장소에 올린 뒤 Settings → Pages에서 배포합니다. Netlify Drop에 폴더를 끌어다 놓는 방법도 됩니다.
2. 아이폰 Safari로 배포된 주소를 엽니다.
3. 공유 버튼 → "홈 화면에 추가"를 누릅니다.

## PC 앱 (Electron, `desktop/`)
같은 웹앱 파일을 데스크톱 창으로 띄웁니다. 창을 닫으면 트레이로 숨고, PC를 켜면 자동 실행되며, 새 하루가 시작됐을 때 창이 숨겨져 있으면 "오늘 복습 N개" 알림을 띄웁니다.
```
cd desktop
npm install          # 처음 한 번
npm run shortcut     # 바탕화면·시작 메뉴 바로가기 만들기 (작업 표시줄 고정용)
npm start            # 또는 "복습 플래너 실행.bat"
```
- 자동 실행은 트레이 아이콘 우클릭 → "PC 켤 때 자동 실행"으로 켜고 끕니다.
- PC 앱의 데이터는 브라우저·폰과 따로 저장됩니다.

## 주의
- 데이터는 기기마다 따로 저장됩니다. PC와 폰은 아직 동기화되지 않습니다.
- 정기적으로 **내보내기**로 백업해 두세요.
- 코드를 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 캐시가 갱신됩니다.
